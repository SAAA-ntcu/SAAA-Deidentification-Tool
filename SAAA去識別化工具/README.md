## 📖 專案背景與定位

「學生學習能力檢測（SAAA, `saaassessment.ntcu.edu.tw`）」為臺灣各縣市教育局處與國小普遍實施之大規模標準化学力評量。隨著生成式 AI 與 AI 代理（Agentic AI）在教育分析領域的普及，教師與研究人員經常需要將評量資料送入 AI 進行班級診斷、學生學習輪廓分析、鑑別度判讀或教學報告撰寫。

然而，原始評量資料包含大量學生真實姓名、班級、座號、學校名稱與所屬縣市，直接交由第三方大型語言模型或雲端服務存在重大個人資料外洩風險，違反《個人資料保護法》。

本工具提供純靜態前端介面，**在使用者電腦的瀏覽器本機端執行 100% 離線去識別化（脫敏）**，支援批次讀取目錄或 `.zip` 壓縮檔，自動辨識 SAAA 系統匯出的 7 大類 Excel 評量報表，精確將學生個人資料、學校資訊與縣市名稱脫敏，並輸出支援 AI 代理直接讀取之 Excel、結構化 JSON 與 Markdown 格式。

本工具依據 SAAA 學力檢測系統固定匯出之資料結構（以 115 年度半導體國小與科技縣之模擬資料為標準規格），自動辨識並處理以下 7 大類 Excel 報表：

| 資料型態 | 模擬資料代表檔名 | 工作表結構與特徵 | 關鍵個資與機敏欄位 | 工具去識別化處理機制 |
|---|---|---|---|---|

| **3. 答對率與等級** | `115年度_半導體國小_數學5年級_答對率.xlsx` | 單一工作表 `Worksheet`。記錄全校學生整體答對率、縣市 PR、全國 PR、等級描述及各分項能力向度答對率。 | • 學校代碼、學校名稱<br>• 年級、班級、性別<br>• **「學生代碼」欄位（SAAA 匯出實存中文姓名）** | • 學校代碼轉 `999999`，校名轉別名<br>• 學生姓名欄位脫敏為跨科假名代號或於公開模式移除<br>• 完整保留整體答對率、PR 值、等級與向度百分比（如「數與計算」、「空間與形狀」） |

| **7. 縣市試題分析** | `115年度_科技縣_縣市試題分析.xlsx` | 工作表以科目年級命名（如 `數學5年級`）。記錄縣市常模層級之題項鑑別度、答對率與各選項分佈。 | • 標題列縣市名稱（如「科技縣」）<br>• 檔案名稱中之縣市名稱 | • 標題列與檔名中縣市名稱替換為縣市別名（如「測試縣」）<br>• 完整保留題目鑑別度與縣市常模參考數據 |


> 📌 **重要技術細節說明：**
> 1. **學生姓名跨表一致性（Cross-file Mapping）**：SAAA 系統匯出「作答反應」與「答對率」時，欄位標題固定為「學生代碼」，但欄內數值實為學生真實中文姓名（如「劉捷」），且未附帶座號；而在「個人成績」卡片中，學生姓名與座號則並列於第 3 列。本工具內建雙鍵映射機制（`StudentMapper`），自動以 `年度_年級_班級_姓名` 進行跨表關聯，確保「個人成績」、「作答反應」與「答對率」在研究模式下，同一位學生獲配完全一致的跨科假名代碼（如 `STU_115_0001`）。
> 2. **個人成績卡片座標校準**：卡片表第 3 列中，`B3` 為姓名、`D3` 為座號、`F3` 為能力等級（精熟/基礎/待加強）。本工具精確鎖定 `D3` 進行座號移除，確保 `F3` 能力等級完好無損。

## 🔬 兩大去識別化模式

| 比較項目 | 🔬 研究分析模式 (Research Mode) | 🌐 公開資料模式 (Public Mode) |
|---|---|---|
| **核心使用情境** | 交付 AI 代理進行**跨科串聯診斷、個人學習輪廓建構、長期成長追蹤** | **資料對外發布、政府開放資料、新聞稿公布、交付未信任之外部模型** |
| **學生姓名處理** | 轉換為跨科一致假名代碼（如 `STU_115_0001`） | **徹底刪除**姓名欄位；個人成績卡片標籤改為 `學生_1成績` |
| **座號欄位處理** | 預設移除（可選保留） | 徹底移除座號欄位 |
| **學校與縣市** | 學校代碼改為 `999999`，校名與縣市替換為別名 | 學校代碼改為 `999999`，校名與縣市替換為別名 |
| **對照總表** | ✅ 自動產出 `mapping_table.xlsx` 與 `mapping_table.json` | ❌ **不產出任何對照表**（不可逆，零留存） |
| **AI 交付安全準則** | 僅交付脫敏後之評量檔案，**對照總表務必由校端本機加密留存，切勿提供給外部 AI** | 處理成果可直接公開或交付任何 AI 工具，無個資外洩隱憂 |

## ⚙️ 參數設定與多格式輸出

### 1. 隨機安全學校別名池 (School Alias Pool)
為杜絕使用者在手動輸入別名時誤填真實學校名稱，系統預設從 10 組公立名山別名中隨機挑選：
- `日月潭國小`、`阿里山國小`、`玉山國小`、`太魯閣國小`、`墾丁國小`
- `合歡山國小`、`奇美國小`、`雪霸國小`、`陽明山國小`、`綠島國小`
學校代碼固定統一替換為標準教育虛擬代號 `999999`。

### 2. 縣市別名設定
提供「測試縣」與「測試市」標準匿名選項，自動掃描全台 22 縣市名稱並進行精準替換。

### 3. 三種輸出格式支援
使用者可於介面選取匯出檔案格式，系統於打包 ZIP 時自動轉換：
- **📊 活頁簿格式 (`.xlsx`)**：保持原始試算表格式，供教師以 Excel / LibreOffice 開啟與校內研討。
- **📝 結構化格式 (`.json`)**：將各工作表轉為標準 JSON 陣列或物件，適合提供給 Python 腳本、自動化分析流程或 LangChain / Semantic Kernel 等 AI 代理管道。
- **🚀 報表格式 (`.md`)**：將各工作表轉為標準 Markdown 表格，文字體積精簡，可直接貼入 ChatGPT、Claude 等 LLM Prompt 上下文中進行試題診斷與提問。

## 🚀 快速開始 (使用指引)

1. 用任何現代瀏覽器開啟 [**`index.html`**](index.html)（雙擊即可開啟，無需安裝伺服器環境）。
2. 將包含評量 Excel 檔案之資料夾或 `.zip` 壓縮檔**直接拖入網頁中間的虛線拖曳區**。
3. 系統即時顯示「總評量檔案」、「個人成績」、「作答反應」、「答對率與等級」、「班平均」與「試題分析」統計指標。
4. 選擇所需的去識別化模式（交付 AI 建議選「研究分析模式」）與輸出格式。
5. 點擊 **「步驟 4：開始執行去識別化並打包下載」**。
6. 瀏覽器本機端執行完畢後，自動觸發下載脫敏完成之 ZIP 壓縮檔（例如 `去識別化後評量資料_合歡山國小_research.zip`）。

## 🛡️ 資安與隱私合規驗證 (Zero-Error & Zero-Leak)

- **100% Client-Side 運算**：所有檔案讀取、字串解析、Excel 重構與 ZIP 封裝皆於瀏覽器 JavaScript 記憶體中執行，無後端伺服器、無任何網路封包傳輸。
- **全域隱私安全審計**：轉換完成前，引擎對輸出檔案進行全域掃描，確認原始學校名稱、縣市名稱與學生真實姓名之洩漏次數為 0。
- **對照總表分離存放原則**：在研究分析模式下產出之 `mapping_table.xlsx` 包含學生代碼與真實身分對應關係，屬於法定機敏個資。校端行政人員應將其存放於具備存取權限控管之離線媒體中，**切勿將對照總表上傳至任何雲端模型或外部代理**。
